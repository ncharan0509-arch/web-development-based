## Introduction
This report combines three beginner-friendly web development case studies created using HTML and CSS. Each project uses a separate HTML file and a separate CSS file. The HTML files provide the page structure and content, while the CSS files control the layout, colors, spacing, typography, cards, and responsive behaviour.

## Objectives
- Practise creating web pages with HTML.
- Apply CSS styling to improve the appearance of a website.
- Use navigation links to move between sections of a page.
- Organize content into sections and cards.
- Use Flexbox and media queries for responsive layouts.
- Learn how HTML files are connected to their corresponding CSS files.

## Tools and Technologies
- **HTML5:** Page structure and content.
- **CSS3:** Styling, layout, colors, spacing, hover effects, and responsive design.
- **Web browser:** To open and test the pages.
- **Text editor:** To view or edit the HTML and CSS files.

## Case Study 1: Personal Portfolio Website

### Aim
To create a personal portfolio website that introduces a student, displays technical skills and projects, and provides a contact section.

### Description
The website presents Charan Teja as a B.Tech Computer Science and Engineering student. It contains an introduction, an About Me section, technical skills, project examples, and contact information.

### Main Features
- Header with the student's name and navigation links.
- Hero section with a short introduction and a “Know More” link.
- About Me section with a brief profile and college name.
- Technical skills displayed as cards: HTML, CSS, Python, and JavaScript.
- Project cards for a personal portfolio and a college website.
- Contact section and footer.

### Files
- `1case.html` — contains the portfolio page structure.
- `1case.css` — styles the page with a blue colour theme, cards, spacing, and a mobile layout.

### HTML and CSS Concepts Used
HTML sections, headings, paragraphs, navigation anchors, links, `div`, `article`, CSS classes, Flexbox, gradients, hover styling, and a media query.

### Expected Result
A clean, blue-themed personal portfolio that lets visitors navigate between the About, Skills, Projects, and Contact sections.

## Case Study 3: Online Learning Platform Interface

### Aim
To design a simple online learning platform interface that displays beginner-friendly courses.

### Description
The LearnHub page introduces an online learning platform and displays courses in Web Development, Python Programming, and UI/UX Basics. Each course card includes a short description, instructor name, level, lesson count, and an enrollment link.

### Main Features
- Header with LearnHub branding and navigation links.
- Hero section introducing the learning platform.
- Popular Courses section with three course cards.
- Course icons and descriptions.
- Instructor names and beginner-level lesson information.
- “Enroll Now” links and a “Why LearnHub?” section.
- Footer with the platform name.

### Files
- `3case.html` — contains the LearnHub page structure.
- `3case.css` — applies a purple and indigo theme, course cards, icons, spacing, and responsive layout.

### HTML and CSS Concepts Used
HTML sections, navigation anchors, links, `div`, `article`, CSS classes, Flexbox, gradients, borders, shadows, hover styling, and a media query.

### Expected Result
A modern-looking learning platform landing page that presents courses in easy-to-read cards. This is a front-end demonstration only: the enrollment links do not create accounts or enroll students.
